# Public Scientific Voice

Use this guide for website project pages and other public scientific prose.
Do not force it onto code comments, internal notes, or casual messages.

## Structure

Prefer a compact version of this argument:

1. Start with the broad scientific or behavioral problem.
2. Use “However,” to name the concrete limitation or gap.
3. State the question, evidence, or method precisely.
4. End with the specific scientific payoff, using “Ultimately,” only when it
   adds real meaning.

## Style

- Use “we” for the scientific community and “I” for Gabriel's work.
- Name methods and what they measure: Neuropixels recordings, pose estimation
  using DeepLabCut, generalized linear models, or hidden Markov models.
- State hypotheses and comparisons directly.
- Prefer explicit causal links among movement, sensory encoding, internal
  state, task structure, and performance.
- Use complete, evidence-grounded sentences. Avoid em dashes and decorative
  fragments.
- Useful connectors include “However,” “For example,” “In addition,”
  “Importantly,” “Taken together,” “Therefore,” and “Ultimately,”.

## Avoid

- Generic emphasis such as “delve into,” “underscore,” “robust,” “nuanced,”
  “landscape,” “unlock,” or “transform.”
- Conclusions that claim broad importance without naming what the work
  clarifies.
- Decorative “not only X, but Y” constructions.
- Prose that could appear unchanged on any neuroscience website.
- Starting a sentence with “But”; use “However,” when the contrast matters.

## Terminology and attribution

- Use **V1** for primary visual cortex. Preserve VISp only in verbatim source
  text, titles, or dataset labels.
- Task-independent movement (TIM) was developed in Churchland Lab work.
  Describe it as a measure Gabriel uses, not one he developed.
- Publications contain Gabriel-authored work only. Background literature
  belongs on the annotated Background Papers page.

## Final check

- Does every sentence make a specific claim?
- Are the method, limitation, and scientific question named?
- Could a general reader understand the chipmunk task, TIM, or Neuropixels
  without internal lab context?
- Is the final payoff tied to the actual experiment or model?
